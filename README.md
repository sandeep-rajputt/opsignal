# OpSignal

**Status:** 🚧 In Active Development

OpSignal is a monitoring and alerting platform designed to keep you informed about your infrastructure and applications. Building something powerful and reliable, one commit at a time.

## What I'm Building With

### Frontend

- **Next.js 16** - The foundation of our UI
- **TypeScript** - Because we like knowing what our code does
- **React Hook Form** + **Zod** - Form handling that doesn't make you want to flip tables
- **Redux Toolkit** + **RTK Query** - State management and data fetching
- **Framer Motion** - Making things move smoothly
- **React Aria** - Accessible components that actually work
- **Tailwind CSS** - Styling without the headaches

### Backend

- **Node.js** + **Express** - Server stuff
- **TypeScript** + **Zod** - Type safety on both ends because consistency matters
- **PostgreSQL** - Where the data lives
- **Redis** - Fast storage for the things that need speed
- **BullMQ** - Queue management for background jobs
- **Resend** - Email delivery that actually reaches inboxes

### What's Next?

More tools will be added as needed. No point in over-engineering before knowing what problems need solving.

## Current State

This project is in development. Things will break, APIs will change, and that's okay. If you're here early, welcome to the chaos.
